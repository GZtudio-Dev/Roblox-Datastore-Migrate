# 🗄️ Datastore Migrator — GZtudio

Migrate player data between Roblox universes with a clean, browser-based GUI.

---

## 🚀 Quick Start

1. **Download** and extract the ZIP
2. **Double click** `START.bat`
3. That's it — browser opens automatically ✅

> Requirements: [Python 3.8+](https://www.python.org/downloads/) — make sure to check **"Add Python to PATH"** during install.

---

## ✨ Features

- 🖥️ Clean browser-based GUI — no terminal needed
- 📡 Real-time migration log
- 🧪 Dry Run mode — simulate without writing data
- 🔄 Support Standard & Ordered Datastore
- 📊 Success/failed counter + elapsed timer
- 🔑 Secure — API key stays on your machine

---

## 🔧 Usage

| Field | Description |
|---|---|
| API Key | Your Roblox Open Cloud API Key |
| Source Universe ID | Universe to migrate **from** |
| Target Universe ID | Universe to migrate **to** |
| Datastore Name | e.g. `PlayerData` |
| Key Prefix | Optional filter (e.g. `user_`) |
| Datastore Type | Standard or Ordered |
| Dry Run | Simulate only, no data written |
